# 《江格尔》十二英雄——基于手写 WebGL 管线的史诗数字展陈交互系统

> 2026 年第十四届全国大学生数字媒体科技作品及创意竞赛（CMIT）
> 申报赛项：**指定命题「民族文化 创新表达」作品赛项**

一个把**超大规模非遗三维资产**压到能在手机里真实旋转的软件系统，并以蒙古族英雄史诗
《江格尔》的十二英雄作为它的第一个完整应用场景。

---

## 这个仓库是什么

**作品本体是一个软件系统，不是一个展馆页面。** 交付物分两层：

| 层 | 内容 | 入口 |
|---|---|---|
| **应用实例**（文化应用） | 十二英雄数字展陈、3D 模型、纹样解读、文化问答、站内检索 | `index.html` |
| **工程与数据证据**（软件本体） | 技术控制台、知识图谱与史料溯源、AI 辅助叙述、资产处理管线 | `console.html` / `graph.html` / `ask.html` |

`index.html` 顶部有「评审入口」区块通往另外三页；构建期有两条门禁断言这个入口不能断
（详见下方「构建门禁」）。

---

## 快速开始

```sh
npm run build      # 全量构建：跑全部门禁 → 生成三个页面 → 打包 dist/
npm run preview    # 预览构建产物（默认 http://127.0.0.1:4173）
npm run dev        # 预览源码（改样式时用）
```

**不需要 `npm install` 就能构建。** 运行时零第三方依赖：无 Three.js、无 Draco 解码器、
无 CDN、无第三方字体。`sharp` 只在重新生成模型贴图时需要（见文末）。

## 可验证性：门禁与验收

本项目的主张都配了可复跑的检查。**任一失败即构建中止**，不产出"看起来正常、实际缺东西"的站点。

| 命令 | 检查内容 |
|---|---|
| `npm run build` | 按依赖顺序跑下列全部门禁，再生成页面与打包 |
| `npm run assets:verify` | 传输/原始体积预算、索引类型、量化扩展、**manifest 与实际资产逐字段一致** |
| `npm run graph:check` | 知识图谱结构、来源引用完整性、无来源断言必须标「待核对」 |
| `npm run ask:check` | AI 叙述模块**47 条边界测试**（覆盖全部十二英雄 × 定义式/可解释/未记载事实/站外） |
| `npm run knowledge:check` | 语料与微信小程序端**逐条一致**（跨端复用同一套语料与同一套检索实现） |
| `npm run test:selfcontained` | `ask.html` 自包含性：不得含运行时 `fetch`，须有初始化失败兜底 |
| `npm run test:dist` | **端到端产物验收**：四页可访问性、引用资源完整性、真实浏览器控制台错误、AI 模块实际问答、首页入口可达 |
| `npm run test:migration` | **迁移验证**：用一件与江格尔无关的资产跑通同一套管线（13 条断言） |
| `npm run test:all` | 上述 + 模型/离线/布局/检索等既有检查 |

### 三条"本地正常、上线才炸"的缺陷（已修，并加了门禁）

| 缺陷 | 后果 | 现在怎么防 |
|---|---|---|
| 构建页面清单写了两遍，两处都漏 `ask.html` | AI 叙述模块不在交付产物里 | `PAGES` 单一真源 + 产物存在性断言 |
| 构建只复制 `src/*.js`，从未复制 `src/data/*.json` | 部署后 AI 模块 **404 失效** | 显式复制 + 逐字节一致断言 + 扫描 JS 里 `fetch` 路径 |
| 离线外壳只预缓存 `index.html` | 断网时四个页面全打不开 | 传入全部页面 + 收集数据集（现 29 项 / 3.06 MiB） |

`ask.html` 另有一类风险被**根因消除**：静态托管在路径不存在时会回退返回 `index.html`
（HTTP 200 + `text/html`），运行时 `fetch` 不会失败在状态码上而会失败在 `r.json()` 解析上，
**页面看起来正常、AI 模块静默变空**。因此语料改为**构建期内联**，该页不再发起任何运行时数据请求。

## 迁移验证（"可复用"的实测证据）

```sh
npm run test:migration
```

1. `tools/make-toy-asset.mjs` 用**零外部依赖**的程序化建模生成一件**陶罐**资产
   （672 顶点 / 1,248 三角面 / 17.4 KiB），带 `KHR_mesh_quantization` 量化与内嵌 PNG 贴图；
2. 写一份独立配置（只改 `outputDir` / 预算口径 / `manifestPath`）；
3. 用**同一个 `assetctl.mjs`**，以 `--config` 指向该配置跑出独立报告；
4. **13 条独立断言**：原始字节与文件一致、gzip 与现场压缩结果一致、量化扩展被识别、
   顶点/三角面数与 GLB accessor 一致、每顶点 13 字节、贴图尺寸解析正确、预算全过、
   **主配置未被改动**。

产出落盘 `migration-demo/`（资产与报告入库，作为证据）。

## 部署

```sh
npm run build
# 然后发布 dist/（Cloudflare Pages / GitHub Pages / 任意静态托管）
```

- **必须发布 `dist/`，不要上传仓库根目录。** `public/models/` 含约 53 MiB 精细模型，
  而 `dist/models/v/` 已按内容哈希组织，最大单文件 6.84 MiB（平台限 25 MiB）。
- 部署后设置域名并重新生成 SEO 与分享元数据（否则 canonical / og:url / sitemap 指向占位域名）：

  ```sh
  SITE_ORIGIN=https://你的域名 npm run build
  ```

- 部署后建议对线上地址复验一次：`npm run test:dist -- https://你的域名`
- 首次访问测试条件：5 Mbps 下行 / 100 ms 延迟 / 冷缓存 → 首次可交互 1,813 ms，
  精细版 6,746 ms 就绪；二次访问可交互 357 ms。

## 已知限制（如实列出，不回避）

- **文化内容是文创演绎，不是史料。** 十二英雄形象为本项目设计；知识图谱中
  **11 项标「待核对」、8 条关系无来源**，均已在页面上显式标注。
- **传承人核对尚未实施**：数据里 `reviewedBy` 保持 `null`，计划写入 `reviewPlan` 字段，
  **不把计划写成成果**（见 `scripts/normalize-provenance.mjs`）。
- **小程序 AR 为"测试中"**：代码已合入、12 尊逐个跑通真机路径，但平面检测与
  锚定漂移的根因未修复、缺真机验证。
- **无运营数据**：无访问量、无用户数、无传播效果。性能指标不是传播效果。
- 小程序主包 **1,499.8 KiB / 1,500 KiB 上限**，余量仅 36.2 KiB。
