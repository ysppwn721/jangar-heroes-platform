# public/media

这个目录放序幕的视频素材。

## 现在里面是什么

`prologue.mp4` / `prologue.webm` 是**占位文件**（无视频轨的最小 MP4），
作用有两个：
1. 通过构建门禁——`scripts/build.mjs` 会断言"页面引用的资源必须存在"；
2. 让 `<video>` 处于可播放状态而不是 error 状态，否则浏览器可能不显示 poster，
   序幕会变成空白。

## 真实素材到位后怎么做

直接覆盖同名文件即可，**HTML 一行都不用改**：

```
public/media/prologue.mp4     ← 1920×1080，8–15 秒循环，≤3 MB
public/media/prologue.webm    ← 同内容的 webm 版本（更小，优先加载）
```

## 素材要求

| 项 | 建议 | 理由 |
|---|---|---|
| 时长 | 8–15 秒循环 | 太长观众等不起，太短没氛围 |
| 分辨率 | 1920×1080，首帧即关键帧 | 首帧就是 poster |
| 体积 | ≤ 3 MB | 不能拖慢首屏 |
| 内容 | 草原空镜、马群、风、火、织物特写 | 不要用现成影视片段（版权） |
